# event-decor-services

## Responsive Event Decor Business Website (Portfolio Demonstration)
A modern, responsive website built for an event & party decoration business.  
This project showcases a clean, premium UI with a soft pastel theme, service packages, tabbed sections, and mobile-first navigation patterns.

## Project Overview
This website was designed to represent a real-world business offering event styling and decoration services such as:
- Custom backdrops, signage, and tablescapes
- Balloon installations, florals, candles, and centerpieces
- Coordinated rentals and setup/takedown support
- Slumber party (teepee) package options

## Key Features
- Responsive layout optimized for desktop, tablet, and mobile
- Tab-based package sections (With Balloons / Without Balloons / Slumber Parties)
- Accessible tab interactions (ARIA roles + keyboard support)
- Polished “glass” UI panels, soft shadows, and consistent theme tokens
- Reusable components (cards, badges, CTA buttons, callouts)
- Clean structure suitable for scaling into a multi-page site

## Tech Stack
- HTML5
- CSS3 (custom properties, responsive breakpoints)
- JavaScript (UI interactions + accessibility enhancements)
